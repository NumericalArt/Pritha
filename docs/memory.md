# Memory

- `.memory/techscope.sqlite`
- `.memory/last-rebuild.sql`
- `.memory/schema.sql`
- `.memory/last-self-test.json`
- embeddings generated by `scripts/embed-memory.py`

Pritha uses a portable full-memory snapshot. Markdown files remain the
canonical authored knowledge, but GitHub should also carry the working memory
state: SQLite, FTS, relations, embeddings, schema, rebuild SQL and the latest
self-test baseline.

## Commands

```sh
node scripts/validate-memory.mjs
node scripts/rebuild-memory.mjs
node scripts/query-memory.mjs stats
node scripts/query-memory.mjs search "agent factory"
node scripts/query-memory.mjs semantic "agent factory"
```

## Rules

- Keep generated indexes rebuildable from Markdown.
- Commit `.memory/` as the portable memory snapshot for Pritha.
- Curated artifacts must have frontmatter.
- Raw JSON, transcripts, text, PDFs and small supporting images are portable
  raw source state.
- Heavy raw audio/video media stays local until a Git LFS/archive policy is
  selected.
- Raw sources stay raw; standards and decisions require curated evidence.

## Why this may matter

Продолжить обзор обновлений Pritha: проверить полезность интерактивных MCP
интерфейсов, агентных SDK, модульного harness и текущего coding runtime.
Разделить библиотеку API, собственный agent loop и управление готовым агентом.

## Processed status

Сохранены нейтральные метаданные и переработанные выводы. Исходный разговор,
выдача поиска, remote README и private runtime state не сохраняются.
Проверенные технические references помещены в assessment.

- Какую конкретную возможность получает Pritha или будущий child agent?

устаревшего knowledge guidance без установки внешнего кода.
